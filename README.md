# Site Storino Corretor Energia iGreen

Site estático responsivo em HTML, CSS e JavaScript. Não exige servidor próprio nem banco de dados. O formulário monta uma mensagem e abre o WhatsApp; os dados não são enviados para um servidor pelo site.

## Arquivos
- `index.html` — conteúdo e seções
- `style.css` — identidade visual e layout responsivo
- `script.js` — menu mobile e formulário para WhatsApp
- `CNAME.example` — exemplo de configuração para domínio próprio
- `PUBLICACAO.md` — instruções de publicação

## Antes de publicar
1. Confira o número de WhatsApp em `script.js` e nos links `wa.me` do `index.html`. O site foi configurado com `5519920134713` (Brasil + DDD 19 + número informado).
2. Revise os textos comerciais e confirme que todas as alegações, condições e regras do programa estão atualizadas e autorizadas.
3. Adicione fotos próprias/licenciadas se desejar substituir as ilustrações feitas em CSS.

## Teste local
Abra `index.html` em um navegador. Para testar o formulário, o dispositivo precisa conseguir abrir o WhatsApp ou WhatsApp Web.
